# 设计样机

两份都是零外部脚本的单文件 HTML，直接用浏览器打开。

| 文件 | 用途 |
|---|---|
| `desktop-simulation.html` | **桌面模拟** —— 像用真软件一样点着看：拖动、双击新建、右键换色、三种形态、三档层级 |
| `tinted-paper-mockup.html` | **规范样本册** —— 1:1 尺寸标注、色板对比度实算、中文排版实证 |

---

## `desktop-simulation.html`

整屏桌面模拟，带任务栏/程序坞、桌面图标、壁纸。用来回答「多种形态值不值得做」：

- **形态**：桌面散落 / 停靠侧栏 / 便笺墙 —— 三者共用同一个组件和同一份状态，切换时不新建任何窗口，这正是它们便宜的原因
- **层级**：普通 / 置顶 / 贴桌面 —— 切到「贴桌面」时左侧绿色那张会沉到桌面图标之下，这是需求 4 里两种语义的分歧点
- 拖顶栏移动、双击顶栏折叠成胶囊、双击空白处新建、右键换色、正文可直接编辑

页面底部有一张成本表，把「便宜的形态」（同一窗口换布局）和「贵的形态」（要新窗口类或新 OS 集成）分开。

## `tinted-paper-mockup.html`

「淡彩纸 Tinted Paper」视觉方向的高保真可交互样机，零外部脚本，直接用浏览器打开。
所有数值取自 [第 12 章 · 设计系统规范](../docs/12-设计系统规范.md)，不是另画一套。

包含：桌面场景（多窗口 + 壁纸压力测试）· 便笺解剖（1:1，带尺寸标注）·
10 色色板（对比度页面内实算）· 主窗口 · 团队便笺墙 · AI 面板 · 中文排版实证。

交互：
- **平台切换** Windows / macOS —— 圆角、caption、字重三处分叉当场可见
- **主题** 跟随系统 / 亮 / 暗
- **壁纸** 浅色 / 深色照片 / 花哨 —— 用来压力测试「窗口边界靠不透明纸面 + 1px 同色相描边自足，不靠阴影」这条主张
- 点便笺切换聚焦，看「退半步」；悬停聚焦的那张看工具栏双条件触发

## 色板的可复现性

10 色便笺色板锁在 OKLCH `L=0.915`（暗色 `0.290`），失焦「退半步」色由 `L+0.006 / C×0.80` 生成。
`palette.py` 复现这套算法并做两项校验：

```
python3 design/palette.py
```

1. 用规范给出的唯一例子验证生成器：柠檬 `#EBE7A4` → `#EBE8B3`（逐位一致）
2. 复算全部对比度，与规范声称的区间比对

实测结果：10 色明度极差 **0.0017**；`ink/paper` 10.55–10.69:1（AAA）；
`ink2/paper` 4.63–4.73:1（AA）；`dot/paper` 3.50–3.94:1；`focus/paper` 4.08–4.28:1 —— 均与规范一致。
