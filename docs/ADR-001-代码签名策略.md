# ADR-001 · 代码签名策略：v1 不买证书，macOS 用自签名身份

| | |
|---|---|
| 状态 | **已采纳**（2026-09-06，产品负责人拍板） |
| 覆盖 | 第 3 章 §2.4.1 / §2.4.2、第 9 章 §8.9、RUNBOOK D1、`.github/workflows/desktop.yml`、用户手册 §2 |
| 复议条件 | 见 §5 |

## 1. 决定

- **Windows：不做 Authenticode 签名。** 用户手册写清两道拦截怎么点过去。
- **macOS：不买 Apple Developer Program，但必须用一张自签名证书给每次构建签名。** 禁止 ad-hoc。
- **两平台的自动更新包依然用 minisign 签名**（`tauri-plugin-updater`），这与代码签名无关，是防中间人替换更新包的，不能省。
- `desktop.yml` 改为：签名 secrets **存在则签、不存在则按上面两条走**；有人以后买了证书，只需填 secrets，不改流水线。

## 2. 为什么

$99/年 + Azure Artifact Signing 月费，对一个还没验证需求的 v1 是可以推后的支出。**推后的代价是可量化、可逆的**（见 §3），而且用户装完之后的体验与签名版**完全一样** —— 因为 Gatekeeper 与 SmartScreen 只拦"从浏览器下载下来的文件"，应用自己下载并替换自身的自动更新**不带隔离标记，不会再被拦**。所以代价是"每个用户第一次装的时候多走几步"，不是"每次都这样"。

## 3. 用户会遇到什么（原样写进用户手册）

| 平台 | 第一次安装 | 之后 |
|---|---|---|
| **Windows** | ① 浏览器下载时提示"不常下载" → 点"保留"；② 双击弹 SmartScreen 蓝屏，"仍要运行"按钮**藏在"更多信息"后面**；发布者一行显示"未知发布者"是**预期的** | 自动更新无提示 |
| **macOS** | 双击 → "Apple 无法验证…" → 点**完成**（别点"移到废纸篓"）→ 系统设置 → 隐私与安全性 → 滚到底 → **仍要打开** → 输密码。**macOS 15 起右键"打开"已不再绕过 Gatekeeper**，只剩这条路；备选：终端 `xattr -d com.apple.quarantine /Applications/bianfa.app` | 自动更新无提示 |

## 4. macOS 为什么"必须自签名、禁止 ad-hoc"

Apple Silicon 上二进制**必须**有签名才能运行，Tauri 在没有身份时默认 ad-hoc 签名。ad-hoc 的签名身份是**每次构建都变的 cdhash**，而 macOS 的 Keychain 授权与 TCC 权限（通知等）都按签名身份记录：

- 登录凭据在 Keychain → **每次自动更新后用户被登出**
- 通知权限 → **每次更新后重新弹授权**

自签名证书（`openssl` 一分钟，$0）给出一个**跨构建稳定的身份**，Keychain 与权限跨更新保留。Gatekeeper 仍拦第一次（它只认 Apple 签发的证书），但那是一次性的。

生成：`infra/ci/make-selfsign-cert.sh`，输出三个 secret 填进 GitHub Environment `release`：`MACOS_SELFSIGN_P12` / `MACOS_SELFSIGN_P12_PASSWORD` / `MACOS_SELFSIGN_IDENTITY`。`desktop.yml` 里 macOS 断言 `codesign -dv` 输出**不含** `Signature=adhoc`，ad-hoc 构建直接红灯。

**这张证书的私钥就是应用身份。** 丢了换一张 = 存量用户在那次更新后重新登录一次（不是灾难，但要知道）。备份到密码管理器；它的重要性低于 updater 的 minisign 私钥（后者丢了是永远推不了更新）。

## 5. 什么时候回头买

任何一条成立就重开本 ADR：

1. "打不开 / 装不上"的支持工单让你觉得比 $99/年更贵
2. 有企业客户，其 IT 策略拦截未签名可执行文件（Windows AppLocker / macOS MDM）
3. 要上 Microsoft Store / Mac App Store（两者都强制签名）

**切换成本**：填 secrets 即可，流水线不改。macOS 从自签名切到 Developer ID 会换一次身份 → 那一次更新用户重新登录一次，之后干净。Windows 签上之后 SmartScreen 警告**不会立刻消失**，新发布者要几周到几个月累积信誉 —— 这也是本决定不急的原因之一。
