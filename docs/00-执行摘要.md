# 执行摘要（Executive Summary）

> 给谁看：一个有 Hostinger VPS、准备自己（或带 1-2 人）把这个产品做出来的开发者。
> 下面每一条都是判断，不是选项。凡是我没核实的数字，都写了"待核实"——**不要拿它们做采购决策**。

---

## 1. 一段话结论

这是一个 **Tauri 2.11.5 桌面客户端 + Yjs CRDT 离线优先同步 + Hostinger VPS 单机后端（Postgres 18 + Node + Redis）+ Cloudflare 只做边缘（DNS/WAF/R2 分发/Tunnel）+ provider-agnostic LLM 网关** 的产品。技术上没有做不出来的部分，但有两处**没有 SDK 兜底、必须自己写 native 代码**的硬骨头：Windows/macOS 的"贴桌面"窗口层级，和 CRDT 同步的正确性。工期：**MVP（P0，约 34 人天）4-7 周可出**，**完整产品（含团队、AI、计费、签名分发）单人现实档约 10 个月 / 190-230 人日**——注意这是"一年只有 250 个工作日、上线后 support 吃掉 15% 时间"之后的数字，不是理想估算。钱：**0 用户时固定成本约 $35-60/月**（VPS 续费价 + Cloudflare + 发信 + 监控），加上首年一次性的代码签名与开发者账号投入（Apple $99/年、Windows 签名方案，二者**均待核实**）；AI 默认 BYOK，平台代付只作有硬熔断的试用额度。

---

## 2. 十条最重要的技术决策

1. **桌面框架选 Tauri 2.11.5，不选 Electron**——便笺天然是多窗口应用，Electron 每窗口一个 renderer 进程；且 Windows 的窗口层级 hack 必须写 native 代码，Rust 在 Tauri 里是编译链一等公民。**Cargo.toml 必须 pin 到 `~2.11`**（用 `with_webview` 时上游明确要求锁 minor）。
2. **Windows 贴桌面用 z-order 沉底（HWND_BOTTOM 周期重放 + 四态状态机），不用 `SetParent` 到 WorkerW**——后者会把窗口变成 `WS_CHILD`，收不到键盘和 IME。**便笺必须能打字，这一条一票否决。**（第 10 章的 spike 描述里还写着 WorkerW，那是过时的，以第 2 章为准。）
3. **正文用 Yjs 13.6.32 CRDT，元数据也放进同一个 `Y.Doc` 的 `Y.Map('meta')`，不用记录级 LWW**——便笺的头号场景就是"公司改一条、回家又改同一条"，LWW 在这里会静默吞掉一半内容；元数据进同一文档则直接消灭了 outbox 的乐观锁 + 409 rebase 整条状态机。
4. **v1 砍掉实时协同基础设施，只在 HTTP 上跑 CRDT 增量同步**——省掉约 60% 服务端工作量（一个有状态长连接 fan-out 服务），保留 100% 的合并正确性；多光标是纯增量，v1.1 装个包就有。
5. **编辑器绑定用 `@tiptap/y-tiptap` 3.0.9，不是 `y-prosemirror`**——后者停在 2025-07-03，抄旧教程会装错包；Tiptap 三个包的 peerDep 写死精确版本，锁文件必须提交。
6. **`yrs` 必须显式设 `OffsetKind::Utf16`**——默认是 `Bytes`，一个汉字 UTF-8 占 3 字节、UTF-16 占 1 单位。这个 bug 在纯英文测试里 100% 不复现，只在中文和 emoji 上串位，而中文正是本产品的主语料。
7. **账号用 Better Auth 1.7.2 自托管，且必须开 `advanced.trustedProxyHeaders: true`**——零 MAU 计费、用户表能和 note 表 JOIN；不开这个开关，在 VPS + Nginx 反代下所有 OAuth 回调地址会生成成 `127.0.0.1`，登录全线失败。
8. **首启动不登录、本地即用，登录后做一次幂等 claim 迁移**——我们替代的是"双击图标光标就在闪"，任何"先注册后使用"会在第一屏流失大部分用户；同时服务端 `user` 表不需要匿名账号，避开合并/配额/GDPR 三重复杂度。
9. **迁移器一律 `PRAGMA table_info(Note)` 按列名匹配 + 候选名回退，位置正则必须允许负坐标**——列漂移已被实证（18 列 vs 19 列），多显示器左/上屏坐标为负，`\d+` 会静默漏掉这批用户。经典版 `plum.sqlite` 是唯一可读的迁移路径，新版没有。
10. **中文搜索：本地 FTS5 用 bigram shingling（或 trigram + 1-2 字 LIKE 旁路），服务端用 PGroonga 建 `(workspace_id, content_text)` 多列索引**——trigram 对不足 3 个 code point 的输入不产 token，"会议""报销"这类 2 字查询恒 0 命中；坚决不用需要跨三平台编译签名的原生分词扩展。

## 3. 正面回答你的 5 个问题

### Q1：完美复刻便笺所有功能 + 账号云同步 —— 能做，但"完美"要打个折

CRUD、关闭≠删除、无边框拖拽窗口、7 色 + 深色、5 项富文本 + 待办、多显示器位置记忆、置顶、快捷键，全部 P0 复刻，约 34 人天。**不复刻的三件**：手写墨迹、图片 OCR、Insights/Cortana（后者后端已死，是遗迹不是功能）。**云同步能做且比原版强**（CRDT 不丢字），但要知道一个时间窗口：迁移只对经典版 UWP Sticky Notes 成立，已完全迁到新版并删掉旧数据的用户**无法自动迁移**——微软哪天下架经典版，这条获客抓手就自然枯竭，**越早做价值越高**。

> 需要你拍板：墨迹到底做不做。需求原文是"完美复刻所有功能"，而 Windows 便笺历史上支持墨迹——砍掉它是明确违背需求，这个取舍不该由技术团队单方面决定。

### Q2：团队管理 + 共享便笺 —— 能做，但 v1 要克制

模型是 **Organization → Workspace → Note 三层，Team 作为授权主体**，`workspaces.team_id` 为 NULL 表示 org 全员、非 NULL 限该 team（**这一列是必须的**，少了它 HR workspace 会对全公司可读）。v1.0 只做 **CSS Grid 共享区 + 图钉贴桌面（`note_pins` 表，位置 per-user）**，自由画布推到 v1.2——自由画布含拖拽/缩放/层叠/多选/视口虚拟化/坐标同步，是 4-6 周不是几天。**差异化 100% 来自"从墙上撕一张贴到自己桌面"，不是来自画布。**

一个容易漏的硬伤：**撤销共享后已连接的 WebSocket 房间会继续收发 update**。必须 `pg_notify('authz_revoked')` + 网关 LISTEN + 60 秒定期重校验兜底。以"共享/撤销"为卖点的产品，这条不做就是安全事故。

### Q3：LLM 多模型 —— 你点名的四个，三个坐实、一个要拆

- `opus 5` → **真实**，写 `claude-opus-5`（不带日期后缀，带了会 404）。
- `gpt 5.6` → **是家族名不是模型名**，必须选档：`gpt-5.6-sol` / `terra` / `luna`。
- `gemini 3.8 flash` → **真实**，`gemini-3.8-flash`。
- `deepseek v4 pro` → **真实**，但坑在 `deepseek-chat` / `deepseek-reasoner` **不是它的别名**，是 131K/8K 的独立旧模型，照抄旧教程会静默拿到便宜的错模型。

实现：**除 Anthropic 外全部走 AI SDK v7 + `@ai-sdk/openai-compatible`，Anthropic 一家例外用官方 SDK 直连**（它是唯一需要 5 个以上专有参数、且缓存杠杆最大的厂商）。模型注册表 provider-agnostic，新增模型只填 `priceIn/priceOut/capabilities`。**路由按 capabilities 交集，不按 tier**——DeepSeek 全系 `supports_vision: false`，把 OCR 挂在 fast 档上会直接失败而不是降级。

**成本上：默认 BYOK。**平台代付只给固定次数试用，且必须三层闸门（单用户月成本硬顶 + 每日次数 + 全局月度熔断）。一次 Product Hunt 上榜就能打穿账单。

### Q4：贴桌面 + 置顶 + 双平台 —— 置顶稳，贴桌面要先定义清楚

**置顶没有任何风险**，两个平台各一行 API（macOS 记得补 `FullScreenAuxiliary | CanJoinAllSpaces | Stationary`，否则用户进全屏 App 时便笺消失）。

**"贴桌面"必须先回答一个产品问题**：你要的是「不被工作窗口挡住」还是「像 Wallpaper Engine 那样在图标之下」？

- 前者 → 三档置顶 + Win+D 豁免开关就够，两周工作量直接省掉。
- 后者 → Windows 用 z-order 沉底 + WinEvent hook；macOS 用 `CGWindowLevelForKey(kCGDesktopIconWindowLevelKey) + 1`（**运行时取值，绝不硬编码**）。**macOS 侧有一个未实测的死结**：level 低于 normal 的窗口能否可靠成为 key window 接受中文 IME 输入。如果不能，macOS 只能做成"只读展示 + 双击弹出编辑窗"。

顺带纠正一个普遍误解：**Windows 自带便笺其实就是普通窗口，Win+D 会一起最小化它。**你要做的比原版更强，不是复刻。

### Q5：要不要用 Cloudflare Workers —— **不。用混合：Cloudflare 做边缘，VPS 做核心。**

**一句话理由：便笺是有状态、长连接、强一致的同步系统，Workers 的强项是无状态、短生命周期、就近分发——把连接池、WebSocket 房间、后台 worker 塞进 isolate，你要为每条约束单独买一个补丁产品（Hyperdrive + Durable Objects + Queues），最后系统更复杂、更贵、被单厂商锁死，而你只有 1-3 个人。**

**放 Cloudflare 的（四件，纯收益无架构风险）**：DNS + WAF + DDoS；R2 分发安装包与更新（出网免费，且把 100MB 包挂在 orange-cloud 后面直接分发会踩 Free 计划的非 HTML 缓存条款，**R2 是合规路径不只是省钱路径**）；`latest.json` 更新清单（Worker 按 installId 哈希做灰度，改 KV 即回滚）；Cloudflare Tunnel 把 VPS 公网 IP 彻底藏起来。

**留在 VPS 的**：API、WebSocket 同步、Postgres（RLS / LISTEN-NOTIFY / pg-boss）、后台队列。

**两条必须记住的副作用**：① Cloudflare 反代对非流式 HTTP 有约 100 秒源站超时（返回 524），所以 `/api/llm/*` **必须一律 SSE，首个 chunk 100 秒内发出，哪怕是 `: ping` 注释帧**；② Tunnel 是新增单点，`cloudflared` 跑 2 副本并**提前写好并演练 break-glass 脚本**（放开 443 + 改 DNS A 记录）。

## 4. 最大的三个风险与应对

| # | 风险 | 为什么致命 | 应对 |
|---|---|---|---|
| **R1** | **贴桌面的 native hack 做不出来或被系统更新打破** | 这是唯一的差异点。做不出来，产品退化成"又一个便笺"，后面 190 人日全部沉没 | **第一周前 3 天做 time-box spike，三天做不出来就停掉整个项目或重新定义卖点**。第一天就把它抽象成 `DesktopPin` trait + 三级降级（沉底 → 置顶浮窗 → 全局热键 Peek），业务代码不许依赖它成功；官网文案不把价值全押在这一条上 |
| **R2** | **同步丢数据** | 便笺用户对这件事容忍度为零，丢一次就永久流失，而且原版差评几乎全指向这里 | 本地 append-only update log + WAL；合并前快照保留 30 天可回滚；服务端全量 update log 可回放；**5 天不可砍的正确性测试套件**（3 副本 × 200 次随机编辑乱序交换的收敛性属性测试、含中文与 emoji 的双端互通、pull 事务中途 `kill -9` 崩溃注入）；上线灰度 5% |
| **R3** | **成本模型与采购决策建立在未核实数字上** | 全套文档里的 Cloudflare / GitHub Actions / 代码签名 / 各家 LLM 定价大部分**本轮无法联网核实**；Hostinger 已实证有三处价格是错的，且续费价接近翻倍（KVM 4: $12.99 → $28.99） | 第一周专门排半天，逐条打开官网核对并产出一张**只含已核实数字**的成本表；**一律按续费价做预算**；LLM 成本改用公式 + 月度 80% 告警 + 硬熔断，不写死单价 |

**并列的第四条，因为它不可恢复**：**Tauri updater 的 minisign 私钥丢失 = 存量用户永远无法自动更新，只能手动重装。**这是全项目唯一的不可逆单点故障。第一次发版前必须完成两处离线介质 + 密码管理器备份并写进交接文档；另外内置一个用**独立离线密钥**签名的 kill switch（启动拉 `/v1/notice` 验签，约 150 行），把"私钥泄漏"从灾难降级为可控。

## 5. 如果明天就开始，第一周做什么

> 原则：**先杀风险，再做功能，最后做钱。**第一周一行业务代码都不该写。

1. **D1 上午 —— 在 2-3 台不同补丁级别的真实 Windows 11 上 dump `plum.sqlite`**：`PRAGMA table_info` 跑 Note / Media / Stroke / User / Insight 五张表，完整 DDL 存档进仓库，作为迁移器唯一权威依据（复制时必须连 `-wal` / `-shm` 一起拿，否则读不到最新数据）。同时把经典版快捷键逐个按一遍验证，特别是 `Ctrl+T` 和 `Ctrl+Shift+L`。
2. **D1 下午 —— S0 工具链就绪性检查（半天 time-box）**：Tauri 2.11.5 三平台能出包、TypeScript 7 下 type-aware ESLint / drizzle-kit / Vite 插件链不炸。任一失败就回落到上一个大版本，**不阻塞**。
3. **D1-D3 —— 贴桌面 spike，项目生死判定**：Windows 侧 z-order 沉底 + `SetWinEventHook(EVENT_SYSTEM_FOREGROUND, ...)` + z-order 探针检测显示桌面，在 Win11 23H2 / 24H2 上验证；macOS 侧 `desktopIcon level + 1`，**重点实测能不能用微软拼音/搜狗打字**。三天没结论就执行降级方案并重新定义卖点。
4. **D3 —— 提交代码签名身份申请**：Azure Artifact Signing（或 OV 证书 + 云 HSM）与 Apple Developer Program。**这是整条发布链路上前置期最长的一环**，放到发版前一周申请必然延期。同时确认申请主体是公司还是个人。
5. **D4 —— 多窗口内存 spike**：20 个 300×300 无边框便笺窗口同时开，测常驻内存、新建窗口到可输入的延迟、空闲 CPU。绿灯 <350MB 继续；黄灯上"窗口池 + 懒创建"（约 5 人日）；红灯才考虑单窗口多画布（真实成本 22-30 人日，不是别人说的 8）。
6. **D4-D5 —— Tiptap 3.31.2 + Yjs 13.6.32 + `@tiptap/y-tiptap` 3.0.9 端到端 spike**：两进程各自离线编辑同一段落 200 次后合并，`encodeStateAsUpdate` 输出必须 byte-identical；**语料必须含中文和 emoji**；同时验证 IME composition 期间挂起持久化与 undo 检查点。产出**冻结的三行 Y.Doc 结构约定 ADR**（`body = XmlFragment` / `meta = Y.Map` / `ext = Y.Map`）。
7. **D5 —— 三件杂事，但都是"现在零成本、以后灾难"**：生成 updater minisign 密钥对并完成双离线备份；查产品名的商标（中国商标局第 9/42 类 + USPTO）与域名可用性；把全套文档里所有标 `[待核实]` 的价格逐条核对，产出真实成本表。

## 6. 一句诚实的话

**这个项目的难点从来不在写代码，而在三件没有 SDK 兜底的事：Windows/macOS 的窗口层级 hack（未文档化，随系统更新可能失效）、CRDT 同步的正确性（错了不报错，只是用户的字悄悄没了）、以及一个人扛 10 个月还要做分发。**

**什么情况下不建议做**：如果你只是想自己用——直接买 Notezilla 之类的现成软件，省下 10 个月；如果你不能接受"贴桌面"这个核心差异点可能在第 3 天就被判死刑，并因此需要推翻整个卖点；如果你打算靠它挣钱但没有任何分发渠道——便笺是"够用就行"的品类，用户不会主动去搜替代品，**做出来没人知道，是这个项目最可能的死法，而它跟技术无关**。
