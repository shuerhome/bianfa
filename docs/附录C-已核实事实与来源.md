- StickyNotes.snt 是 OLE2/CFBF 复合文档，每条便笺一个 storage，stream '0' 为 RTF、stream '3' 为 UTF-16 编码纯文本（代码中显式 .decode("utf-16")）；OLE storage 自带 ctime/mtime 可用于恢复便笺时间戳。来源：https://github.com/PythonForensics/PythonForensicsCookbook Chapter09/sticky_notes.py
- SQLite FTS5 内置 trigram tokenizer，接受 case_sensitive 与 remove_diacritics 两个参数（且 remove_diacritics 要求 case folding 开启），能处理非拉丁文字（官方测试用例含泰文 'กรุงเทพมหานคร'）；但它需要至少 3 个字符才产生 token，输入不足 3 字符时直接 return SQLITE_OK 不产出任何 token —— 即 1-2 字的中文查询会返回 0 结果。来源：https://github.com/sqlite/sqlite ext/fts5/fts5_tokenize.c 及 ext/fts5/test/fts5trigram.test、fts5trigram2.test
- Electron 的 BrowserWindow type 选项：macOS 支持 desktop / textured / panel，Linux 支持 desktop / dock / toolbar / splash / notification，Windows 仅支持 toolbar —— 即 Windows 上没有 desktop 窗口类型。来源：https://github.com/electron/electron docs/api/structures/base-window-options.md
