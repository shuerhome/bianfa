# 便笺（bianfa）安装与使用手册

> 一句话：它是 Windows 便笺的替代品——双击图标，光标就在闪，直接打字。多出来的是：能贴在桌面上不被 Win+D 收走、能在两台电脑之间同步而且不丢字、能和团队共享、能用你自己的 AI 帐号帮你改写。**不登录也能一直用，所有本地功能永久免费。**

---

## 1. 系统要求

| 系统 | 要求 | 为什么是这个门槛 |
|---|---|---|
| **Windows** | Windows 10（22H2）或 Windows 11，x64 或 arm64 | 便笺的界面跑在 Windows 自带的 WebView2 上。Windows 10 的常规支持已于 2025 年 10 月结束，22H2 是它最后一个版本、也是唯一还能（通过扩展安全更新）收到安全补丁的版本，更早的 Windows 10 我们不再测试；arm64 设备（如 Surface Pro X 系列）有原生版本，不走模拟 |
| **macOS** | macOS 14.4（Sonoma）或更新，Apple 芯片与 Intel 都支持 | 便笺依赖 macOS 自带的 WebKit 内核，14.4 随附的 Safari 17.4 内核是我们完整测试过中文输入与桌面层级行为的最低版本 |

内存与磁盘：几十张便笺同时开着大约占 300 MB 内存；安装包 20 MB 左右，数据按你的便笺数量增长（纯文字几乎不占空间）。

不支持：Windows 10 22H2 之前的版本（安装器会直接告诉你原因，而不是装完崩溃）、macOS 13 及更早、Linux（暂无计划）。

---

## 2. 下载与安装

只从官网下载：`https://<REPLACE_ME:domain>/download`。其它渠道的安装包我们无法保证没被改过。

### 2.1 Windows

1. 下载 `bianfa_x.y.z_x64-setup.exe`（arm64 设备下载 `_arm64-setup.exe`）。
2. **双击运行。不需要管理员权限**，也不会弹 UAC——它只装到你自己的账户里（`%LOCALAPPDATA%`），同一台电脑上别的 Windows 用户看不到你的便笺。
3. 第一次运行时，**很可能出现一个蓝色的「Windows 已保护你的电脑」窗口。这是正常的，不是病毒。** 点「更多信息」→ 确认「发布者」一行显示 `<REPLACE_ME:publisher-name>` → 点「仍要运行」。

   **为什么会有这个警告？** Windows 的 SmartScreen 不是按「有没有签名」判断，而是按「这个发布者的文件被多少人下载过」积累信誉。我们每一版都用同一个经过身份验证的签名身份签名，但作为一个新发布者，在下载量积累到微软的阈值之前，前几周甚至几个月都会弹这个提示。这不是我们能花钱跳过的东西。**你唯一需要核对的是「发布者」那一行**：如果显示「未知发布者」，说明这个文件不是我们签的，请不要运行，并联系 `<REPLACE_ME:support-email>`。

4. 安装完成后自动启动。安装器会检查 WebView2 运行时（Windows 11 与近几年的 Windows 10 都自带）；如果没有，它会联网下载一个约 2 MB 的引导程序来安装——所以首次安装请保持联网。需要完全离线安装的企业用户，可向我们索取内嵌运行时的离线包（体积大约多 127 MB）。

### 2.2 macOS

1. 下载 `bianfa_x.y.z_universal.dmg`（一个包同时支持 Apple 芯片与 Intel）。
2. 双击打开，把「便笺」图标**拖进「应用程序」文件夹**。
3. 从「应用程序」里正常双击打开即可。**不需要右键「打开」，也不需要去「系统设置」里点「仍要打开」**——我们的应用经过 Apple 公证（notarization），Gatekeeper 会直接放行。
4. 如果你真的看到了「无法打开，因为 Apple 无法检查其是否包含恶意软件」：说明这个文件不是从官网下载的原版（macOS 15 起 Apple 已经取消了「按住 Control 点击」绕过的方式，只能去「系统设置 → 隐私与安全性」底部点「仍要打开」）。**请不要这么做**，重新从官网下载。

首次启动 macOS 会问一次是否允许「便笺」在后台运行（用于开机自启动和菜单栏图标），允许即可；不允许也能用，只是不会开机自启。

## 3. 首次启动

**不需要注册，不需要登录。** 打开就是一张便笺，光标已经在里面。

第一张便笺的内容就是教程（四行：拖动顶栏移动 / 快捷键新建 / 右键换色 / 关闭≠删除），读完直接删掉它就行。托盘（Windows 右下角）或菜单栏（macOS 右上角）会多一个便笺图标——**所有便笺都关掉以后，从这里找回来**。

### 3.1 发现你的旧便笺时

如果这台电脑上装过 Windows 自带的「便笺」（经典版），首次启动会弹出**唯一的一个弹窗**：

> 发现 23 条 Windows 便笺，是否导入？

- 弹窗里是一面**彩色缩略图墙**，每条便笺可以单独勾选或取消，不会不问就全导。
- 默认只把原版里**正在桌面上打开着的**那些便笺贴到桌面，其余进列表——原版你关掉的 30 条不该一次性糊满屏幕。
- 导入完成会给一份报告：`成功 21 / 格式降级 2 / 失败 0`。「格式降级」是指原版里某些我们不支持的元素（比如手写墨迹、图片 OCR 结果）被转成了文字或占位，可以点开逐条对比。
- **你的 Windows 便笺原始文件不会被修改。** 我们会顺手把原始数据库复制一份到我们的数据目录 `imports/` 里——这其实是你以前从来没有过的一份备份。
- 现在不想导？点「稍后」。以后随时可以在「设置 → 数据 → 导入 → Windows 便笺」里做，也可以手动指定文件。还支持 Windows 7 / 8 时代的 `StickyNotes.snt` 文件。

> 注意：能自动导入的只有**经典版**便笺（数据文件是 `plum.sqlite`）。如果你用的是并入 OneNote 的新版便笺，微软没有提供可读的本地数据，我们无法自动导入——只能从 OneNote 里复制粘贴。这也是我们建议**越早迁移越好**的原因。

## 4. 登录与同步

登录只做一件事：把你的便笺同步到你的其它电脑（以及以后的团队共享、AI 试用额度）。不登录，本地一切照常。

### 4.1 怎么登录

1. 托盘菜单 → 「设置…」→ 「账号」→ 「登录」。
2. 便笺会**打开你的系统浏览器**（不在应用里嵌一个登录页——这样你的密码只会输在浏览器里，Google/Apple 也要求这么做）。选「用 Google 继续」「用 Apple 继续」或邮箱。
3. 登录成功后浏览器页面会显示「可以关闭本页了」，**便笺窗口会自动跳回前台**并显示「✓ 欢迎回来」。
4. 浏览器没自动打开？登录窗里有「复制链接」，自己粘到任何浏览器都行。等了 60 秒还没反应？便笺会自动提示「改用邮箱验证码登录」：在任何设备的浏览器打开 `https://<REPLACE_ME:domain>/device`，输入便笺显示的 8 位验证码即可（验证码有有效期，过期重新点一次「登录」就会换新的）。
5. 登录后，这台电脑上已有的便笺会**自动归到你的账号下并上传**，不会出现「登录后本地便笺被云端的空白覆盖」这种事——本机始终是权威副本。

登录状态会一直保持，不用每次重新登录；「设置 → 账号 → 退出登录」会清掉这台电脑上的登录凭据，但**不删除本机便笺**。

### 4.2 离线也能用

断网、飞机上、公司防火墙——随便写。每一次改动先写进本机，再排队等网络。恢复网络后自动补传，顺序不乱、不丢字。

### 4.3 同步指示器怎么读

每张便笺顶栏最右边有一个 6 像素的小点，靠**形状**而不只是颜色区分（色觉障碍也能分辨），鼠标停上去有文字：

| 你看到的 | 意思 | 要做什么 |
|---|---|---|
| **什么都没有** | 已同步 | 不用管。同步正常时我们不画绿勾——那是噪音 |
| **实心点，慢慢呼吸** | 正在同步 | 等几秒 |
| **空心的小圈** | 离线，改动已存在本机、等待上传 | 不用管；长时间空心圈见「常见问题 6」 |
| **红点，右上角有个小缺口** | 这张便笺有需要你决定的冲突 | 点它打开冲突面板 |

托盘菜单里也有一行「● 已同步 · 2 分钟前」的总状态。

### 4.4 「冲突」是什么、为什么很少见

公司电脑改了第 3 行、回家的电脑改了第 5 行，两边都不在线——绝大多数同步软件会让你「二选一」，丢掉一半。便笺用的是**逐字合并**（CRDT）：两边的改动都保留，同一段文字里的改动会交错合并，另一台电脑新写进来的字会**高亮 8 秒**让你注意到。

只有两种情况会打扰你：

- 合并后内容**明显变短**（我们的「长度收缩守卫」认为可能不对劲）：便笺顶部出现一条黄条，可以「查看合并前版本」或「恢复」。这是我们给你的信任担保，宁可多问一次。
- 一台电脑删了、另一台还在改：**编辑胜**，便笺会自动从回收站回来，并给一个轻提示。

真正需要你选的冲突（极少）在「设置 → 同步与冲突」里：左右并排比较，三个按钮——`保留我的` / `保留对方` / `合并为两张便笺`。第三个永远是安全的选择。

## 5. 便笺基本操作与快捷键

### 5.1 日常操作

- **新建**：托盘图标左键（Windows）/ 托盘菜单「＋ 新建便笺」/ 全局快捷键 `Ctrl+Alt+N`（哪怕便笺没在前台）/ 任意便笺内 `Ctrl+N`。新便笺出现在鼠标所在的显示器上，光标已经在里面。
- **移动**：拖顶栏。**改大小**：拖右下角。位置和大小按显示器记忆，拔掉副屏再插回来会回到原位。
- **换色**：右键 / 顶栏调色板，10 种：石墨 · 玫瑰 · 珊瑚 · 琥珀 · 柠檬 · 竹绿 · 松石 · 天青 · 紫罗兰 · 品红。深色模式下每种颜色有对应的深色版。调色板里每格都写着颜色名字，另有「用图案区分便笺颜色」选项给色觉障碍用户。
- **格式**：粗体 / 斜体 / 下划线 / 删除线 / 项目符号 / 待办勾选框，选中文字会浮出格式条。支持粘贴图片。
- **关闭 ≠ 删除**：右上角 ✕ 只是「收起」，内容和位置都在，从便笺列表或托盘「显示全部便笺」找回来。第一次关掉最后一张便笺时会提示一次「便笺还在托盘里」。
- **删除**：更多菜单 ⋯ → 删除，进回收站，**30 天**内可恢复，之后彻底清除。
- **便笺列表**：托盘「打开便笺列表」，可搜索、按颜色/时间筛选、批量操作、看回收站。搜索**中文两个字就能命中**（比如「报销」「会议」）。
- **命令面板**：`Ctrl+K` / `⌘K`，输入动作名或「色:琥珀」直接执行。
- **会议共享屏幕前**：托盘「隐藏全部便笺」一键收，位置全部保留；「显示全部便笺」放回来。
- **字号与缩放**：`Ctrl` + 滚轮 / `Ctrl+=` `Ctrl+-`（macOS 用 `⌘`）调的是这张便笺的正文字号（12–24）；`Ctrl+0` / `⌘0` 把整体界面缩放复位到 100%。整体界面缩放在「设置 → 外观」有 90% / 100% / 115% / 130% 四档。

### 5.2 快捷键

文本编辑类（复制、粘贴、全选、行首行尾）**完全跟随系统习惯**，不另外规定。所有快捷键都可以在「设置 → 快捷键」里改，冲突时会提示是谁占用了。

| 动作 | Windows | macOS |
|---|---|---|
| 新建便笺（全局，便笺不在前台也行） | `Ctrl+Alt+N` | `⌥⌘N` |
| 新建便笺（便笺内） | `Ctrl+N` | `⌘N` |
| 收起当前便笺（不删除） | `Ctrl+W` | `⌘W` |
| 置顶 / 取消置顶 | `Ctrl+P` | `⌘P` |
| 换色（玫瑰 → 品红） | `Ctrl+1` … `Ctrl+9` | `⌘1` … `⌘9` |
| 换色（石墨） | `Ctrl+Shift+0` | `⇧⌘0` |
| 界面缩放复位 100% | `Ctrl+0` | `⌘0` |
| 粗体 / 斜体 / 下划线 | `Ctrl+B` / `Ctrl+I` / `Ctrl+U` | `⌘B` / `⌘I` / `⌘U` |
| 删除线 | `Ctrl+T` | `⌘T` |
| 待办 / 项目符号列表 | `Ctrl+Shift+L` | `⇧⌘L` |
| 缩进 / 反缩进（列表项） | `Ctrl+]` / `Ctrl+[`（`Tab` / `Shift+Tab` 也行） | `⌘]` / `⌘[` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` | `⌘Z` / `⇧⌘Z` |
| 命令面板 | `Ctrl+K` | `⌘K` |
| AI 助手抽屉 | `Ctrl+/` | `⌘/` |
| 把格式操作交给键盘（焦点进格式条 / 切换底部条模式） | `Ctrl+E` | `⌘E` |
| 在便笺窗之间循环（带缩略图） | `Ctrl+Tab` | `⌃Tab` |
| 便笺内查找 | `Ctrl+F` | `⌘F` |
| 删除便笺（进回收站） | `Ctrl+Shift+Delete`（建议值） | `⇧⌘Delete` |
| 打开便笺列表 | `Ctrl+Shift+O`（建议值） | `⇧⌘O` |
| 设置 | `Ctrl+,`（建议值） | `⌘,` |
| 键盘移动 / 调整无边框窗口 | `Alt+Space` 弹出菜单 → 方向键（`Shift` 加速） | — |

`Esc` 永远不会关掉便笺——这是故意的，避免手滑丢内容。输入法正在选字时，`Enter` / `Esc` / 撤销都优先交给输入法。

## 6. 置顶与贴桌面

每张便笺右键 → 「层级」有三档，也可以在便笺属性里设，**按张记忆**：

| 档 | 行为 | 适合 |
|---|---|---|
| **置顶** | 永远盖在其它窗口上面（`Ctrl+P` / `⌘P` 快速切换） | 正在照着做的清单、开会时的提纲 |
| **普通**（默认） | 和别的窗口一样，谁在前谁盖谁 | 大多数便笺 |
| **贴桌面** | 贴在壁纸和桌面图标**之上**、所有工作窗口**之下**；按 `Win+D` / 点任务栏「显示桌面」时**不会被收走**；平时不挡任何东西 | 长期放在桌面上的备忘、待办 |

几件值得知道的事：

- **Windows 自带的便笺其实做不到「贴桌面」**——它就是普通窗口，Win+D 会把它一起最小化。所以第三档是原版没有的功能，不是复刻。
- 贴桌面的便笺**可以直接点进去打字**，包括中文输入法。macOS 上如果你的系统版本下无法直接输入，**双击便笺会弹出一个编辑窗口**，改完关掉即可。
- Windows 上「置顶」挡不住全屏独占的游戏和 UAC 提权窗口，这是系统行为；置顶便笺只在**当前虚拟桌面**显示。
- macOS 上置顶的便笺会跟着你进入其它 App 的全屏模式，也会出现在所有 Space 里，Mission Control 不会把它扫走。
- 输入法候选框被置顶便笺挡住？我们会在便笺获得焦点时自动把层级降半档，一般不会挡；如果还挡，请把系统版本和输入法名称发给我们。
- 快速用户切换、锁屏解锁、休眠唤醒之后，贴桌面的便笺会自动回到桌面层；同步连接也会在唤醒后立刻重连，不用等。

## 7. 团队共享

登录后，「设置 → 团队」可以创建组织、邀请成员。结构是 **组织 → 工作区 → 便笺**：你个人的便笺在个人工作区，**不会出现在任何团队共享区**，除非你主动把它共享出去。

- **邀请**：生成一条邀请链接（网页链接，带有效期），发给同事。角色分「拥有者 / 编辑 / 只读」。
- **共享区**：托盘「打开便笺列表」→ 左侧切到团队工作区，看到的是一面卡片墙，按更新时间排序，谁改了什么实时可见。
- **撕一张贴到自己桌面**：卡片右上角的 **📌 图钉** → 这张便笺会作为一个真正的便笺窗口出现在你的桌面上，和共享区是**同一份内容**，任何人改了都会同步。**贴在你桌面哪个位置只有你自己看得到**，同事可以把同一张贴在他自己屏幕的另一个角。
- **别人共享给你的便笺不会自动出现在你桌面上**——桌面是最私密的画布。它会进「共享给我」收件箱并给你一条通知，你自己决定要不要贴出来。
- **撤销共享**：便笺 ⋯ → 共享 → 移除某人 / 取消共享。对方几秒内就看不到这张便笺了，哪怕他当时正开着。
- 如果你的版本有「保险箱」：放进保险箱的便笺是端到端加密的，服务器看不到内容，因此**不能共享、不能用云端 AI、没有服务端搜索和版本历史**——这是加密的代价，不是 bug。

## 8. AI 助手

`Ctrl+/`（`⌘/`）在便笺右侧拉出 AI 抽屉：改写、缩短、扩写、提取待办、把一段话整理成清单、问问题。结果**先预览**，你点「替换」或「插入」才落进便笺，落进去的内容和你自己打的字一样可以 `Ctrl+Z` 撤销。

### 8.1 为什么默认要你自己带 API Key

每次调用 AI 都要按字数付钱给模型厂商（Anthropic、OpenAI、Google、DeepSeek……）。如果由我们代付，要么把这笔钱摊进订阅价、要么严格限制次数——两种都对重度用户不友好。**用你自己的 Key，你按厂商原价付、想用哪个模型用哪个、内容只发给你自己选的厂商，我们中间不加价。** 这叫 BYOK（Bring Your Own Key），是本产品 AI 的默认方式。

登录用户有一小份**试用额度**（免费版每月 50 点、每天最多 5 次，Pro 版每月 800 点），用来在没配 Key 之前试一试；用完就停，不会偷偷扣费。

### 8.2 怎么填 Key

1. 「设置 → AI 模型 → 供应商 → ＋」。
2. 选厂商，粘贴你在厂商控制台创建的 API Key，点「测试连接」。成功后会自动拉取该厂商可用的模型列表（拉不到也可以手填模型 ID）。
3. 在「已启用的模型」里拖动排序，**第一个就是默认模型**；右侧开关控制在选择器里出现与否。
4. Key 只显示后 4 位；要换 Key 就整体替换。

**Key 存在哪？** 两种模式，在供应商卡片上选：

- **本地直连（隐私模式，推荐）**：Key 只存在你电脑的系统钥匙串里（Windows 凭据管理器 / macOS 钥匙串访问），请求由便笺程序直接发给厂商，**不经过我们的服务器**。
- **云代理**：Key 加密后存在我们服务器上，请求经我们转发。好处是多设备共用一把 Key、有用量统计和自动降级；代价是内容会经过我们的服务器（我们不保存正文，只记 token 数）。

### 8.3 你应该知道的几件事

- 发送前如果检测到**身份证号、银行卡号、看起来像 API Key 的字符串**，会提示你一键遮蔽再发——是否遮蔽由你决定，我们不会自作主张改你的内容。
- 每个厂商「会不会用你的数据训练」「保留多久」「服务器在哪」都写在供应商卡片上，来自我们逐条核对过的厂商条款并标注核对日期。DeepSeek 的服务器在中国大陆，默认不启用，需要你明确勾选。
- 「设置 → 隐私 → AI 活动日志」能看到每次发送了什么、发给了谁，可导出 CSV。
- 组织管理员可以为整个团队关闭 AI；你也可以在「设置 → 隐私」关闭。
- 「云代理」模式下，模型**开始吐出第一个字**最多等 100 秒（这是我们边缘网络的限制），之后逐字流式输出不受限；很慢的深度推理模型请切换到本地直连。

## 9. 更新

**全自动，你不需要做任何事。**

- 便笺启动时和之后每小时检查一次更新。有新版本时在后台静默下载。
- **Windows**：下载完成后，在你下次退出或重启便笺时安装（安装那几秒便笺会自己退出再回来，屏幕上只有一个很小的进度窗——这是 Windows 安装器的限制）。也可以在托盘看到「有更新可用」时点「立即重启」。
- **macOS**：下载完成后替换应用包并提示「重启以完成更新」；不点也没关系，下次启动就是新版。
- 每个安装包都带我们的签名，便笺会**先验签再安装**——签名不对的更新会被直接丢弃，所以中间人替换更新包这条路是堵死的。
- 新版本是**分批推送**的：先给 5% 的用户，观察没问题再放到 25%、100%。所以你的同事可能比你早两天拿到更新，这是正常的。等不及可以「设置 → 关于 → 检查更新」，或直接去官网下载覆盖安装（数据不受影响）。
- 想早用新功能：「设置 → 关于 → 加入 Beta 渠道」。Beta 版可能有问题，不建议在只有一台工作电脑的情况下开。

极少数情况下，如果我们发现某个版本有严重问题，会在你启动时显示一条公告要求手动下载新版——那条公告也是签名过的，便笺会验签后才显示。

## 10. 你的数据在哪、怎么导出、怎么彻底删除

### 10.1 在哪

| 系统 | 位置 |
|---|---|
| Windows | `%LOCALAPPDATA%\<REPLACE_ME:bundle-id>\`（资源管理器地址栏直接粘贴） |
| macOS | `~/Library/Application Support/<REPLACE_ME:bundle-id>/` |

「设置 → 数据 → 本地数据位置 → 在文件管理器中显示」一键打开。

- 主数据库是**整库加密**的（SQLCipher），密钥放在系统钥匙串里。这意味着：把这个文件夹拷到别的电脑、备份到云盘、旧硬盘被人拿走，都读不出内容。**但它不防以你的身份运行的恶意程序**——那种程序同样能读你的钥匙串。我们不会把它说成「不可破解」。
- **不要把这个文件夹放进 OneDrive / iCloud / Dropbox 同步目录**，云盘同步数据库文件是它损坏的头号原因。便笺启动时检测到这种情况会警告你。多设备同步请用登录，不要用云盘。
- `imports/` 里是导入时留下的 Windows 便笺原始文件备份，可以删。
- 便笺的窗口位置也存在本机，**不会**跨设备同步（两台电脑分辨率不同，同步位置只会添乱）。

### 10.2 导出

**不需要登录、不需要联网、不经过服务器**——这是我们写在产品页上的反锁定承诺：

- **全部导出**：「设置 → 数据 → 导出」→ 三种格式任选：
  - **Markdown 文件夹**：每张便笺一个 `.md` 文件，文件头带颜色、创建时间、标签，任何编辑器都能开；
  - **JSON**：完整元数据 + 正文，给程序读；
  - **单文件 HTML**：一个可以直接双击浏览的网页，附件内嵌。
- **单张导出**：便笺 ⋯ → 「导出 MD」。
- **云端账号数据**（含 AI 对话记录、审计记录、附件）：「设置 → 账号 → 导出我的全部数据」，后台打包成 ZIP 后发一封带下载链接的邮件到你的邮箱，链接 24 小时有效。

### 10.3 彻底删除

分两层，按需选：

1. **只删本机**：「设置 → 数据 → 危险区 → 注销并删除本机数据」，需要输入确认文字。它会退出登录、删除本机数据库与附件缓存、清除钥匙串里的密钥。**云端账号里的便笺不受影响**，在别的设备上还在。
2. **删除账号（云端）**：「设置 → 账号 → 删除账号」。立即：所有设备登出、账号进入 30 天宽限期（后悔了登录即可取消）；30 天后：便笺、附件、AI 记录、搜索索引全部物理删除；备份中的副本会随最长 35 天的备份轮转自然消失——我们把这个时间明说，而不是承诺「立即从一切地方消失」。你在团队里共享过的便笺会保留给团队，作者显示为「已删除用户」。

回收站里的便笺 30 天后也会自动彻底清除，「设置 → 数据 → 清空回收站」可以立刻清。

## 11. 卸载

### Windows

1. 托盘图标 → 「退出 bianfa」。
2. 「设置 → 应用 → 安装的应用」→ 找到便笺 → 「卸载」（不需要管理员）。
3. 卸载向导里有一个勾选框「**删除应用数据**」：勾上会一并删掉 §10.1 的数据目录（含所有便笺、附件缓存、导入备份）。想保留数据以后再装回来，就不要勾。
4. 想连钥匙串里的密钥也清掉：「控制面板 → 凭据管理器 → Windows 凭据」，删除名字带 `bianfa` 的条目。这一步可选，留着没有任何影响。

### macOS

1. 菜单栏图标 → 「退出 bianfa」。
2. 把「应用程序」里的「便笺」拖到废纸篓。
3. 数据目录 `~/Library/Application Support/<REPLACE_ME:bundle-id>/` 需要手动删（macOS 没有卸载向导）。
4. 可选：「钥匙串访问」里搜索 `bianfa`，删除相关条目；「系统设置 → 通用 → 登录项与扩展」里如果还列着便笺，移除。

卸载**不会**删除你云端账号里的任何东西。想删账号见 §10.3。

## 12. 常见问题

**1. 我把便笺关了，它去哪了？**
关闭只是「收起」，内容和位置都在。托盘图标 → 「打开便笺列表」或「显示全部便笺」。真正的删除在 ⋯ 菜单里，删了也还有 30 天回收站。

**2. 按了 Win+D 之后便笺不见了。**
默认档是「普通」，和别的窗口一起被收起，再按一次 Win+D 就回来。想让它永远留在桌面上：右键 → 层级 → **贴桌面**。这是原版 Windows 便笺做不到的事，见 §6。

**3. Windows 弹「Windows 已保护你的电脑」，这是病毒吗？**
不是。见 §2.1：这是新发布者积累信誉期间 SmartScreen 的固定行为。点「更多信息」，确认「发布者」显示 `<REPLACE_ME:publisher-name>`，再点「仍要运行」。发布者显示「未知」才要警惕。

**4. 我用的是新版 Windows 便笺（和 OneNote 一起的那个），能导入吗？**
自动导入只支持经典版（`plum.sqlite`）。新版没有可读的本地数据，只能在 OneNote 里手动复制。如果你还没完全迁到新版、旧数据还在，趁现在导。

**5. 两台电脑离线时都改了同一张便笺，会丢吗？**
不会。两边的改动逐字合并（见 §4.4），对方新写的字高亮 8 秒。极少数需要你决定的情况在「设置 → 同步与冲突」里，永远有「合并为两张便笺」这个不丢任何内容的选项。

**6. 同步指示器一直是空心圈。**
说明这台电脑连不上同步服务器，改动都安全地在本机。依次检查：网络是否正常；公司防火墙是否放行 `api.<REPLACE_ME:domain>` 与 `ws.<REPLACE_ME:domain>` 的 443 端口（同步用的是标准的 HTTPS 和 WebSocket，不需要额外端口）；「设置 → 同步」点「立即同步」看错误提示。如果是我们服务器的问题，官网 `https://<REPLACE_ME:domain>` 首页会挂公告。服务器恢复后会自动补传。

**7. 搜「报销」搜不到，但搜「报销单」能搜到？**
不应该出现——我们特别处理过中文两字词。请把具体的词发到 `<REPLACE_ME:support-email>`。顺便：单个汉字搜索会走另一条较慢的路径，两个字以上体验最好。

**8. 一台电脑有好几个 Windows 用户，会互相看到便笺吗？**
不会。程序和数据都装在每个用户自己的目录里（`%LOCALAPPDATA%`），甲用户看不到乙用户的任何东西。每个用户需要各自安装一次（不需要管理员）。

**9. 不登录能一直用吗？以后会不会被锁住？**
能，永远能。三条承诺：① 本地功能永久免费，不订阅也能用；② 你的数据随时可以明文导出（Markdown / JSON / HTML），不需要登录；③ 如果有一天服务要停，提前 90 天通知并提供最终导出。

**10. AI 提示「密钥无效或已过期」/ 我想换个 Key。**
「设置 → AI 模型 → 该供应商卡片 → ⋯ → 编辑」，整体粘贴新 Key 后点「测试连接」。Key 无效的常见原因：厂商那边余额用完、Key 被你在厂商控制台删除了、复制时带了空格。试用额度用完的提示是另一句话（「本月试用额度已用完」），那时填自己的 Key 就能继续。
