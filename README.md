## 一分钟结论

**技术栈**：Tauri 2.11.5 桌面壳（Rust + WebView）· Yjs 13.6.32 CRDT 离线优先同步 · Node 24.20.0 LTS + PostgreSQL 18.6 跑在 Hostinger VPS · Cloudflare 只做零状态边缘 · provider-agnostic 的 LLM 网关。

**工期**：MVP（本地可用版，P0 功能）约 **34 人天 / 4–7 周**。完整产品（含团队、AI、计费、代码签名分发）单人现实档约 **190–230 人日 / 10 个月**——这已扣除「一年只有 250 个工作日、上线后客服吃掉 15% 时间」。

**成本**：0 用户时固定成本约 **$35–60/月**，外加首年一次性的代码签名与开发者账号投入。AI 默认 BYOK（用户自带 Key），平台代付只作有硬熔断的试用额度。

**难点不在写代码**，在三件没有 SDK 兜底的事：Windows/macOS 的窗口层级 hack（未文档化，随系统更新可能失效）、CRDT 同步的正确性（错了不报错，只是用户的字悄悄没了）、以及一个人扛 10 个月还要做分发。

## 正面回答你的 6 个问题

### 1. 完美复刻便笺全部功能 + 账号云同步 → 能做，但「完美」要打个折

CRUD、关闭≠删除、无边框拖拽、7 色 + 深色、5 项富文本 + 待办、多显示器位置记忆、置顶、快捷键 —— 全部 P0 复刻，约 34 人天。

**不复刻三件**：手写墨迹、图片 OCR、Insights/Cortana（后者后端已死，是遗迹不是功能）。

**云同步比原版强**：用 CRDT 而非 last-write-wins，「公司改一条、回家又改同一条」不会静默吞掉一半内容 —— 这正是原版差评的集中点。

> ⚠️ **一个有时间窗口的获客抓手**：一键迁移只对**经典版 UWP Sticky Notes** 的 `plum.sqlite` 成立，微软新版（并入 OneNote）没有可读迁移路径。微软哪天下架经典版，这条抓手就自然枯竭 —— **越早做价值越高**。
>
> ⚠️ **需要你拍板**：手写墨迹到底做不做。你的需求原文是「完美复刻所有功能」，而 Windows 便笺历史上支持墨迹 —— 砍掉它是明确违背需求，这个取舍不该由技术方单方面决定。

### 2. 团队管理 + 共享便笺 → 能做，但 v1 要克制

模型是 **Organization → Workspace → Note 三层，Team 作为授权主体**。v1.0 只做 CSS Grid 共享区 + 「从墙上撕一张贴到自己桌面」，自由画布推到 v1.2（含拖拽/缩放/层叠/多选/视口虚拟化/坐标同步，是 4–6 周不是几天）。

**差异化 100% 来自「撕下来贴到自己桌面」，不来自画布。**

> ⚠️ 一个容易漏的安全硬伤：**撤销共享后，已连接的 WebSocket 房间会继续收发 update**。必须 `pg_notify('authz_revoked')` + 网关 LISTEN + 60 秒定期重校验兜底。以「共享/撤销」为卖点的产品，这条不做就是安全事故。

### 3. 多模型 AI → 你点名的四个，三个坐实、一个是家族名

| 你写的 | 核实结果 | 正确写法 |
|---|---|---|
| `opus 5` | ✅ 真实 | `claude-opus-5`（**不带日期后缀，带了会 404**） |
| `gpt 5.6` | ⚠️ **是家族名不是模型名** | 必须选档：`gpt-5.6-sol` / `-terra` / `-luna` |
| `gemini 3.8 flash` | ✅ 真实 | `gemini-3.8-flash` |
| `deepseek v4 pro` | ✅ 真实 | `deepseek-v4-pro`（注意 ⚠️ 见下） |

> ⚠️ **一个会静默烧钱的坑**：`deepseek-chat` / `deepseek-reasoner` **不是 V4 的别名**，是 131K/8K 的独立旧模型。照抄旧教程会拿到错模型而且不报错。

模型做成**配置化注册表**，新增模型只填 `priceIn/priceOut/capabilities` 一行，不用改代码、不用发版。**路由按 capabilities 交集，不按 tier** —— DeepSeek 全系 `supports_vision: false`，把 OCR 挂在「快速档」上会直接失败而不是降级。

**成本上默认 BYOK**。平台代付必须三层闸门（单用户月成本硬顶 + 每日次数 + 全局月度熔断）——一次 Product Hunt 上榜就能打穿账单。

### 4. 贴桌面 + 置顶 + 双平台 → 置顶稳，贴桌面要先定义清楚

**置顶零风险**，两平台各一行 API（macOS 记得补 `FullScreenAuxiliary | CanJoinAllSpaces | Stationary`，否则用户进全屏 App 时便笺消失）。

**「贴桌面」必须先回答一个产品问题**：你要的是「不被工作窗口挡住」还是「像 Wallpaper Engine 那样在图标之下」？

- **前者** → 三档置顶 + Win+D 豁免开关就够，**直接省掉两周工作量**。
- **后者** → Windows 用 z-order 沉底（`HWND_BOTTOM` 周期重放 + WinEvent hook + 四态状态机）；macOS 用 `CGWindowLevelForKey(kCGDesktopIconWindowLevelKey) + 1`（**运行时取值，绝不硬编码**）。

> ⚠️ **绝对不要用网上流传的 `SetParent` 到 WorkerW 方案**（Wallpaper Engine/Rainmeter 的做法）。它会把窗口变成 `WS_CHILD`，**收不到键盘和 IME 输入**。一个不能打字的便笺不是便笺 —— 这一条一票否决。
>
> ⚠️ **macOS 侧有一个未实测的死结**：level 低于 normal 的窗口能否可靠成为 key window 并接受中文输入法。如果不能，macOS 只能做成「只读展示 + 双击弹出编辑窗」。**这是第一周必须实测的事**。

> 顺带纠正一个普遍误解：**Windows 自带便笺其实就是普通窗口，Win+D 会一起最小化它。** 你要做的是比原版更强，不是复刻。

### 5. 要不要用 Cloudflare Workers → **不。用混合：Cloudflare 做边缘，VPS 做核心。**

**一句话理由**：便笺是**有状态、长连接、强一致**的同步系统，Workers 的强项是**无状态、短生命周期、就近分发**。把连接池、WebSocket 房间、后台 worker 塞进 isolate，你要为每条约束单独买一个补丁产品（Hyperdrive + Durable Objects + Queues），最后系统更复杂、更贵、被单厂商锁死 —— 而你只有 1–3 个人。

| 放 Cloudflare（四件，纯收益无架构风险） | 留在 Hostinger VPS |
|---|---|
| DNS + WAF + DDoS | API 服务 |
| R2 分发安装包与更新（出网免费） | WebSocket 同步服务 |
| `latest.json` 更新清单 + Worker 灰度（改 KV 即回滚） | PostgreSQL（RLS / LISTEN-NOTIFY / pg-boss） |
| Cloudflare Tunnel 把 VPS 公网 IP 彻底藏起来 | 后台队列与定时任务 |

> 💡 R2 分发不只是省钱：把 100MB 安装包挂在 orange-cloud 后面直接分发会踩 Cloudflare Free 计划的**非 HTML 缓存条款**，**R2 是合规路径**。

**两条必须记住的副作用**：
1. Cloudflare 反代对非流式 HTTP 有约 **100 秒源站超时**（返回 524）→ `/api/llm/*` **必须一律 SSE，首个 chunk 100 秒内发出，哪怕是 `: ping` 注释帧**。
2. Tunnel 是新增单点 → `cloudflared` 跑 2 副本，并**提前写好并演练 break-glass 脚本**（放开 443 + 改 DNS A 记录）。

### 6. 前端设计与排版 → 视觉方向已定：**淡彩纸 (Tinted Paper)**

4 个视觉方向经 3 位评审（视觉工艺 / 产品契合度 / 工程可行性）打分，主干取「纸感极简」，嫁接「表达型彩色」的 OKLCH 明度锁定机制：**桌面上是整张淡彩纸，列表里收敛成 3px 色条 + 8px 色点**。10 色便笺色板全部锁在同一 OKLCH 明度，正文对比度极差只有 0.35（全部 10.47–10.82:1，AAA）。

三条写进 CI 的红线：

1. **Windows 承载中文正文的窗口必须不透明** —— Chromium 在带 alpha 的合成面上退回灰度抗锯齿、放弃 ClearType，13px 中文明显发虚。推论（**便笺窗是直角**，因为 DWM 对无边框窗口不保证圆角）一并接受。这条直接判了「Mica/毛玻璃」方向死刑。
2. **便笺静止态常驻 GPU 成本为零** —— 15 个独立 webview 同时开着，禁止常驻 `filter`/`backdrop-filter`/`will-change`。
3. **平台分叉只允许在 chrome 层，且不得改变换行结果** —— 同一张便笺在两台电脑上换行位置不同，对同步型产品是**正确性缺陷**，不是审美差异。

> ⚠️ **中文界面显廉价的头号原因**：微软雅黑只有 400/700，**没有 500/600**。写 `font-weight:600` 会触发合成假粗，把 13px 中文笔画糊成一团。所以 Windows 下层级靠「字号 + 颜色 + 字距」建立，不靠字重，并全局 `font-synthesis-weight:none`。
>
> ⚠️ **中文标点排版是个真坑**：`text-spacing-trim`（全角标点挤压）Chrome 123+ 支持但 **Safari 至今未实现**；`hanging-punctuation` 反过来只有 WebKit 有；`palt` 在苹方生效、在雅黑无效。裁定是**两平台同开或同关，绝不做单边渐进增强**，靠一个自制的 ~5–8KB 标点子集字体（把闭合标点 advance 静态设为 0.5em）绕开引擎差异。

## 第一周做什么

> 原则：**先杀风险，再做功能，最后做钱。第一周一行业务代码都不该写。**

| 天 | 事项 | 判据 |
|---|---|---|
| **D1 上午** | 在 2–3 台不同补丁级别的真机上 dump `plum.sqlite`，`PRAGMA table_info` 跑五张表，DDL 存档进仓库 | 列漂移已被实证（18 列 vs 19 列），必须按列名匹配而非位置 |
| **D1 下午** | 工具链就绪性检查（半天 time-box）：Tauri 三平台出包、TS7 下 lint/drizzle/Vite 链不炸 | 任一失败即回落上一个大版本，**不阻塞** |
| **D1–D3** | 🔴 **贴桌面 spike —— 项目生死判定** | **3 天做不出「沉底后还能打中文」→ 降级为三档置顶，并重新定义卖点** |
| **D3** | 提交代码签名身份申请（Azure Artifact Signing + Apple Developer） | 这是整条发布链上**前置期最长**的一环，放到发版前申请必然延期 |
| **D4** | 20 个便笺窗口内存 spike | 绿 <350MB 继续；黄上窗口池；红才考虑单窗口多画布（真实成本 22–30 人日） |
| **D4–D5** | 🔴 **CRDT 端到端 spike**：两进程各离线编辑 200 次后合并，输出必须 byte-identical | **语料必须含中文和 emoji**；产出冻结的 Y.Doc 结构 ADR |
| **D5** | 生成 updater minisign 密钥对并**双离线备份**；查商标与域名；逐条核对所有 `[待核实]` 价格 | 见下方 ⚠️ |

> ⚠️ **全项目唯一不可逆的单点故障**：Tauri updater 的 minisign 私钥丢失 = 存量用户永远无法自动更新，只能手动重装。第一次发版前必须完成两处离线介质 + 密码管理器备份，并内置一个用**独立离线密钥**签名的 kill switch（约 150 行），把「私钥泄漏」从灾难降级为可控。

## ⚠️ 核实边界（重要，请勿跳过）

本方案的事实核查是分层的，**不同层级的可信度不同**：

| 层级 | 内容 | 可信度 |
|---|---|---|
| ✅ **一手核实** | 包版本号（registry.npmjs.org / crates.io / Docker Hub 实测）、开源项目源码与文档、CSS 特性支持（caniuse / WebKit blog / MDN BCD）、Hostinger VPS 官网价格 | 高，附来源链接 |
| ⚠️ **二手核实** | OpenAI / Google / DeepSeek 的模型 ID 与定价，来自 LiteLLM 的 `model_prices_and_context_window.json`（社区维护的镜像，非厂商官方页） | 中，**采购前必须以厂商官网复核** |
| ❌ **未核实** | Windows 版本生命周期、商标费用与周期、部分 SaaS 定价、应用商店条款编号 —— 第 11 章执行时 WebSearch 配额已耗尽、通用出口被策略拦截，一律标了 `[待核实]` | **不要拿它们做采购决策** |

核实过程中被**推翻的初稿错误**（说明核查确实起了作用，也说明凭记忆写方案有多危险）：

- Hostinger KVM 4 续费价实为 **$28.99** 而非 $14.99（促销价与续费价接近翻倍，**预算一律按续费价做**）
- DeepSeek 缓存命中价初稿写错 **2 倍**；gpt-5.6 的 `$5/$30` 与 `$10/$45` 均错误
- `edoburu/pgbouncer:1.24` **根本不是有效 tag**
- PostgreSQL 18 的 `io_method=io_uring` 在 Docker 默认 seccomp 下**不可用**（`io_uring_setup` 不在白名单），直接推翻原本的数据库调优结论
- 经典版便笺 `Note` 表**确实有 `IsAlwaysOnTop` 列**，初稿「旧版不支持置顶」的断言被 Eric Zimmerman 的官方取证 map 推翻
- 暗色模式三级文字对比度算错：基准只标了它在 canvas 上的 5.02:1，**漏了「暗色下 surface 越高越亮、三级文字越危险，方向与亮色相反」**，实测跌破 AA

---

## 什么情况下不建议做

- **如果你只是想自己用** —— 直接买 Notezilla 之类的现成软件，省下 10 个月。
- **如果你不能接受「贴桌面」在第 3 天就被判死刑**，并因此需要推翻整个卖点。
- **如果你打算靠它挣钱但没有任何分发渠道** —— 便笺是「够用就行」的品类，用户不会主动去搜替代品。一键迁移是唯一的天然获客抓手，而它有时间窗口。

## 需要你拍板的四件事

方案把能自己裁的都裁了（设计规范 11 条未决冲突已在[第 18 章](docs/18-设计规范终审裁决.md)终审），剩下这四条是产品/商业判断，不该由技术方单方面决定：

| # | 决策 | 代价是明码的 |
|---|---|---|
| 1 | **手写墨迹做不做** | 你要求「完美复刻所有功能」，而便笺历史上支持墨迹。方案砍了它 —— 这是明确违背需求 |
| 2 | **「贴桌面」要哪个语义** | 「不被工作窗口挡住」→ 直接省掉两周；「像壁纸一样在图标之下」→ 要写 native，且 macOS 侧存在未实测的 IME 死结 |
| 3 | **macOS 最低版本 13 → 14.4** | 技术上无争议（13 自 2025-09-15 起不再收安全更新，其 WKWebView 是个冻结引擎，而我们要把 AI 返回的内容渲染进去）。但「不服务哪部分存量」是商业判断 |
| 4 | **Windows 便笺窗取消「最小化」按钮** | 220px 顶栏放不下 80px caption，且 `skipTaskbar:true` 下最小化会丢窗口。若坚持保留，最小窗口下限必须上调，连带作废 220×220 的容量账 |
